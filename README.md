# 🏋️ BearBulk Website V0.1

An **e-commerce website** built for the **BearBulk sportswear brand**, featuring product pages, shopping cart functionality, and MySQL database integration.  
This is version **V0.1** of the project, serving as the first functional prototype for BearBulk’s online store.

---

## 📦 Features
- **Landing page** with brand introduction (`home.html`)  
- **Category pages** for Men, Women, and Accessories (`men.html`, `women.html`, `accessories.html`)  
- **Shopping page** with product listings (`shopping.html`)  
- **Shopping cart system** (`shopping_cart.php`)  
- **Database integration** (MySQL, `bearbulk.sql`)  
- **Responsive frontend** using HTML, CSS, and JavaScript  

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL (`bearbulk.sql`)  
- **Assets:** images, stylesheets, scripts

## ▶️ How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/KhaledYaish0/BEARBULK_WEBSITE-V0.1.git
   cd BEARBULK_WEBSITE-V0.1
   
2. Import the database:

- Create a MySQL database (e.g., bearbulk_db)

- Import the provided bearbulk.sql file

3. Configure the database connection:

- Update db.php with your MySQL credentials

4. Run the project:

- Place the project in your local server directory (e.g., XAMPP htdocs)

- Start Apache & MySQL

- Open http://localhost/BEARBULK_WEBSITE-V0.1/home.html in your browser
